# Pedagogical motif source attribution

The compiled files in `motifs/` are derivative high-contrast, transparent 400x400 PNGs. The authoritative source, creator, license, and pedagogical use for each output are recorded in `asset_manifest.json`.

Source files are curated from Wikimedia Commons. CC BY and CC BY-SA material must retain the linked attribution and license in any redistributed package. Public-domain and CC0 sources are retained with source attribution for provenance.

The source asset pack is intentionally small: it provides recognisable realia for worksheet and flashcard templates, rather than attempting to attach an image to every lexical record.
