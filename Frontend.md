Frontend & UI Layer (Stitch to Compose)Jetpack Compose: The entire UI will be built using this modern, declarative toolkit. Intention: Compose is highly compatible with AI-generated layouts from Stitch, allowing Antigravity to easily translate design tokens into modular Android components without heavy XML overhead.Kotlin Native: The app will be written strictly in native Kotlin, deliberately avoiding cross-platform frameworks like Flutter. Intention: Avoiding intermediate virtual machines is mandatory to survive the strict 2GB RAM device limit and to provide direct hardware audio bindings.ViewModel & StateFlow (MVVM): The state management architecture. Intention: To cleanly decouple the Stitch-generated UI from the heavy machine learning pipeline, ensuring the screen remains perfectly fluid and jank-free while translations compute in the background.Edge AI Inference Stack (The 2GB RAM Engine)CTranslate2 via C++ JNI: The execution engine for your fine-tuned IndicTrans2 NMT model. Intention: It utilizes INT8 dynamic quantization and memory mapping (mmap), strictly capping the active translation RAM footprint to ~120 MB to prevent Android's Low Memory Killer from instantly crashing the app.Sherpa-ONNX: The acoustic backbone for the Speech-to-Text module. Intention: It continuously transcribes the 16kHz Hindi audio stream locally on the tablet's CPU with extreme efficiency.  Piper TTS (VITS): The synthesizer for your trained Santali audio model. Intention: Engineered specifically for offline execution, it generates natural audio natively on the device to guarantee we meet the strict sub-3-second latency budget.  Offline Routing & Data ManagementSQLite (Room Persistence): The local caching engine. Intention: Acts as our "Tier-1 Router" to intercept standard curriculum commands, delivering zero-latency text lookups (< 15 ms) that completely bypass the heavy neural models.Kotlin Coroutines: Asynchronous concurrency management. Intention: Safely sequences the ASR, MT, and TTS operations on background threads so the main UI never freezes during real-time speech processing.
